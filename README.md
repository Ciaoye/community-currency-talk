# 俏也的分享

入口：https://ciaoye.github.io/community-currency-talk/

- `community.html`：我的社区货币路演演示版，保留选定的 41 页。
- `nonconsumer.html`：我的不消费主义分享演示版，保留选定的 100 页，包含社区货币部分。
- `article.html`：我的不消费主义加社区货币分享会文章版，目前为整理中的预留页面。

两个演示版均为公开阅读版本：方向键或按钮翻页，页码滑块跳页，目录导航、全屏、默认收起的讲稿栏目（电脑左右分栏、手机上下分栏）。每页有 `#slide-N` 链接。首尾页有微信二维码，可点击放大。没有选页、删除、导出和自动播放时间轴，也不读取旧版本的本地选页状态。

讲稿整理仅去掉录音时间、说话人标签和其他人的插话，保留俏也的原有叙述文字。社区路演及过渡部分沿用原演示稿的讲稿；这些段落是此前根据理念材料组织的草稿，不能当作现场逐字实录。页面上的“我的叙述”是演示的阅读辅助，不是新完成的文章版。

页面沿用原演示的版式、插图和交互。联系二维码为作者提供的原始图片；展示裁切通过 CSS 实现，没有重绘二维码。

GitHub Pages 从 `main` 分支根目录发布，`.nojekyll` 保留静态文件。
